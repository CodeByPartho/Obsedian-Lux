## Overview

**Obsidian Lux** is an avant-garde digital storefront for luxury retail. Built around an aesthetic of deep obsidian tones, gold accents, and subtle typography, the application merges interactive particle systems and fluid layout transitions with on-demand personal styling assistance.

---

## Key Features

- **Modern Dark Aesthetic** — Modern dark UI with glassmorphic depth, dynamic particle atmospheres, and typographic precision.
- **Interactive Styling Concierge** — In-app conversational styling advisor to help clients curate wardrobes and discover limited edition garments.
- **Interactive Product Showcase** — Fluid gallery view, responsive detail cards, high-resolution zoom, and real-time cart interactions.
- **Cinematic Micro-Interactions** — Smooth hardware-accelerated animations and scrolling tickers engineered via Motion.
- **Cutting-Edge Stack** — Fast hot module reloading and build speeds via Vite 6 and Tailwind CSS v4.
- **Admin & Inventory Control** — Built-in panel for managing product catalogs, sizing metrics, and inventory counts.

## Getting Started

### Prerequisites
- **Node.js**: `>= 18.x`
- **npm**: `>= 9.x`

### Installation & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/CodeByPartho/Obsedian-Lux.git
   cd Obsedian-Lux
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure environment variables (Optional)**:
   Create a `.env` file in the project root if using remote concierge services:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. **Launch the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

5. **Build for production**:
   ```bash
   npm run build
   ```
